# 算法6逻辑验证矩阵

“实际行为”来自纯 C 单元测试或代码路径审查；没有连接实体车辆，因此硬件列均未冒充通过。

| 场景 | 预期行为 | 实际代码行为 | 安全 | 后续硬件验证 |
|---|---|---|---|---|
| 所有传感器正常 | 自动跟随并避障 | UWB→VFH→双轮 PID | 是 | 必须 |
| UWB 超时 | 停止前进，短时搜索后空闲 | 0.7 s 失效，SEARCH 后 IDLE | 是 | 必须 |
| UWB 目标丢失 | 不使用旧目标持续前进 | 时间戳门限使目标无效 | 是 | 必须 |
| UWB 数据异常 | 丢弃坏帧 | 解析校验失败不更新时间戳 | 是 | 必须 |
| 雷达无数据 | 超声波降级 | field 过期后传 NULL | 有限安全 | 必须 |
| 雷达部分无效点 | 忽略坏点 | 距离/质量/角窗过滤 | 是 | 必须 |
| 左超声失效 | 使用右超声和雷达 | 左时间戳过期 | 有限安全 | 必须 |
| 右超声失效 | 使用左超声和雷达 | 右时间戳过期 | 有限安全 | 必须 |
| 双超声失效 | 仅雷达，网页显示故障 | 两侧无效不注入 | 有限安全 | 必须 |
| 左编码器无脉冲 | 停车并锁存故障 | 0.6 s 检测后中立停车 | 是 | 必须 |
| 右编码器无脉冲 | 停车并锁存故障 | 0.6 s 检测后中立停车 | 是 | 必须 |
| 编码器方向相反 | 不允许持续错误闭环 | 需要台架标定；错误通常触发失反馈/偏差 | 有限安全 | 必须 |
| FSR 断线 | 告警，不制造假重量 | 自检 raw<10 输出 WARN | 是 | 必须 |
| FSR 满量程 | 告警 | 自检 raw>4085 输出 WARN | 是 | 必须 |
| 网页切 AUTO | 清零手动命令 | mode handler 清零 v/w | 是 | 已代码审查 |
| 网页切 MANUAL | 自动控制失去权限 | 控制任务只执行手动命令 | 是 | 已代码审查 |
| 网页断开 | 中立停车 | Wi-Fi 断开/1 s 心跳超时后急停接口 | 是 | 必须 |
| 急停 | 最高优先级立即中立 | 锁存标志先于模式/算法判断 | 是 | 必须 |
| 急停恢复 | 显式 CLEAR，旧命令不恢复 | CLEAR 清零手动命令 | 是 | 必须 |
| ESC 初始化失败 | 不启动控制任务 | `app_main` 返回 | 是 | 必须 |
| UART 初始化失败 | 不启动对应任务 | 返回值检查，其他传感器降级 | 是 | 必须 |
| 部分传感器失败 | 保留可用路径并显示状态 | 只创建成功初始化的任务 | 有限安全 | 必须 |
| 车辆重启 | 先中立并保持 2 s | 初始化后立即 1500 us，再解锁等待 | 是 | 必须 |
| 任务阻塞/看门狗风险 | 停车 | 底盘 0.3 s 无新设定值自动中立 | 是 | 必须 |

已执行的模拟：`tests/algorithm/run_tests.sh` 覆盖混控饱和、PID/抗积分饱和、目标正常、目标丢失、空闲、避障和急停；`tests/protocol/run_tests.sh` 覆盖超声波校验、UWB 正常/坏帧和 FSR 标定边界。
