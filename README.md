# 智能跟随行李箱 · 跟随算法3（Kalman + 自适应PID + S曲线 + 预测跟踪）

**跟随算法3 = 引入业界主流跟随算法技术，在相同传感器/引脚基础上，大幅提升跟随平滑性、响应速度和鲁棒性。**

相比跟随代码1的简单 P 控制器，本算法参考了市面上商用跟随机器人（如 Follow-You 行李箱、服务机器人）的典型控制策略，引入信号滤波、自适应控制、轨迹平滑、预测补偿和传感器融合等8项改进。

## 跟随代码1 → 跟随算法3 改进总览

| # | 改进项 | 跟随代码1 | 跟随算法3 | 效果 |
|---|--------|----------|----------|------|
| 1 | **Kalman滤波** | 无，直接使用UWB原始值 | 对距离/方位分别1D Kalman滤波 | UWB噪声显著降低，跟随更平稳 |
| 2 | **自适应PID** | 固定P增益 | 距离P随误差自适应放大，方位P随速度自适应 | 远距离快速追赶，近距离精细控制 |

## 核心算法详解

### 改进1: Kalman滤波 (信号平滑)

**问题**: UWB距离测量噪声约σ=20cm，方位噪声约σ=5°，直接使用原始值导致机器人抖动。

**方案**: 对距离和方位分别应用一维Kalman滤波器，状态为位置估计。

**滤波模型**:
```
预测:  x̂_k|k-1 = x̂_k-1        (位置不变假设)
       P_k|k-1 = P_k-1 + Q     (Q: 过程噪声)

更新:  K_k = P_k|k-1 / (P_k|k-1 + R)   (R: 测量噪声)
       x̂_k = x̂_k|k-1 + K_k * (z_k - x̂_k|k-1)
       P_k = (1 - K_k) * P_k|k-1
```

**参数选择**:
- 距离Q=0.03, R=0.16: 约70%信任滤波估计，显著平滑
- 方位Q=0.02, R=0.08: 平衡响应速度和噪声抑制

### 改进2: 自适应PID增益

**问题**: 固定增益在远近不同距离下无法兼顾——远距离需要大增益快速追赶，近距离需要小增益避免超调。

**方案**:

**距离自适应**:
```
kp_eff = kp_dist * (1 + 3 * min(|error|/3m, 1.0))
```
误差越大，增益越高。3米误差时增益放大4倍，快速追近。

**方位自适应**:
```
if speed < 0.3m/s:  kp_eff = kp_bear * 1.5   (低速，转向灵活)
if speed > 0.6m/s:  kp_eff = kp_bear * 0.7   (高速，保持稳定)
```

### 改进3: S曲线速度剖面 (Jerk限制)

**问题**: 原方案使用恒定加速度ramp，加速度的突变 (jerk) 导致车轮打滑和机械冲击。

**方案**: 限制加加速度 (jerk = da/dt)，而非仅限制加速度。

**实现**:
```
desired_a = error * 3.0                              // 比例趋近
desired_a = clamp(desired_a, -max_accel, max_accel)  // 加速度限制
Δa = clamp(desired_a - current_a, -jerk*dt, jerk*dt) // 加加速度限制
current_a += Δa
current_v += current_a * dt
```

默认参数: max_jerk=1.5 m/s³, max_accel=0.8 m/s²

### 改进4: 预测目标跟踪

**问题**: 机器人跟踪的是UWB测量的"过去"位置，存在约200-500ms滞后。

**方案**: 维护最近8帧目标位置的滑动窗口，通过线性回归估计目标在机器人坐标系下的运动速度，然后跟踪预测位置。

**预测公式**:
```
predicted_dist = current_dist + est_dist_rate * 0.3s
predicted_bear = current_bear + est_bear_rate * 0.3s
```

超前0.3秒预测等效于补偿了传感器的延迟和系统的响应时间。

### 改进5: 阿基米德螺线搜索

**问题**: 原地旋转搜索覆盖范围呈扇形，目标走到侧面或后方时无法重捕获。

**方案**: 螺线 r = a·θ 不断向外扩展：
```
progress = search_time / timeout         // 0 → 1
v_fwd = 0.08 + 0.05 * progress           // 逐步加速前进 (0.08→0.13 m/s)
       + 0.15 * sin(phase * 2)           // 小幅正弦摆动
w = search_rps * (0.2 + 0.8 * progress)  // 扩大旋转半径
  * sign(last_known_bearing)             // 朝最后已知方向
```

搜索半径随时间线性扩大，覆盖面积 ∝ t²。

### 改进6: 互补滤波 IMU + 编码器航向融合

**问题**: 纯IMU欧拉角噪声大，纯编码器差速响应慢。

**方案**: 频域互补滤波：
```
fused_yaw_rate = α * gyro_z + (1-α) * enc_yaw_rate
fused_yaw = ∫ fused_yaw_rate dt
```

- α=0.98: 高速动态信任陀螺仪 (高频响应好)
- 编码器差速提供长期无漂移基准 (低频稳定性)
- 融合航向用于IMU航向闭环修正

### 改进7: 动态跟车距离

```
dynamic_distance = base_distance + speed_factor * |target_speed|
```

- 目标静止: 跟车距离=1.0m (基础距离)
- 目标慢走0.5m/s: 跟车距离=1.25m
- 目标快走1.0m/s: 跟车距离=1.5m (上限)

速度因子默认0.5 (即每秒速度增加0.5m距离)。

### 改进8: 增强状态机 (4态 + 迟滞)

```
                        目标出现
     ┌─────────┐ ═════════════════► ┌───────────┐
     │  IDLE   │                    │  FOLLOW   │
     │  停车    │ ◄───────────────  │  正常跟随  │
     └─────────┘   搜索超时(6s)     └───────────┘
          ▲                              │  ▲
          │             目标丢失          │  │ 目标移动
          │          ┌──────────┐        │  │
          └──────────│ SEARCH   │◄───────┘  │
                     │ 螺线搜索  │           │
                     └──────────┘           │
                                       ┌───────┐
                                       │ASLEEP │
                                       │低功耗待机│
                                       └───────┘
                                    目标静止>30s + 距离OK
```

**状态切换迟滞**: 进入SEARCH需丢失>1s (而非0.5s)，防止频繁抖动。
**ASLEEP模式**: 目标静止超过30秒且距离在停止带内，进入低功耗待机。目标一动即自动唤醒。

## 跟随控制公式 (FOLLOW状态)

**输入**: UWB解析出目标位置 → Kalman滤波 → 预测补偿 → `{d, β}`

**线速度**:
```
err = d - dynamic_follow_dist
kp_scale = 1 + 3 * min(|err|/3, 1)

if err > 0:  v = adaptive_PID(err, kp_scale)   // 自适应PID + S曲线
else if |err| < stop_band: v = 0               // 停止带
else: v = 0                                     // 太近，不倒车
```

**角速度**:
```
kp_scale = f(speed): 1.5x(<0.3m/s), 1.0x, 0.7x(>0.6m/s)
w = adaptive_PID(0, β, kp_scale)               // 使β→0
```

**转向-速度耦合**:
```
v *= (1 - |β| / 90°)                           // 大转角时减速
```

**IMU+编码器航向闭环**:
```
fused_yaw = CF(gyro_z, enc_yaw_rate, α=0.98)
yaw_ref += w * dt
w += heading_kp * wrap(yaw_ref - fused_yaw)
```

**S曲线平滑输出**:
```
cmd_v = s_curve(v_des)
cmd_w = s_curve(w_des)
```

## 调参指南

### 跟随平滑度调优

1. **如果跟随抖动大**:
   - 增大 `KF_DIST_R` (4000-6000) 和 `KF_BEAR_R` (2000-4000) → 更强滤波
   - 减小 `KF_DIST_Q` (50-100) → 降低系统对变化的敏感度
   - 增大 `MAX_JERK` (2000-3000) → 允许更柔和的加速

2. **如果跟随响应慢**:
   - 减小 `KF_DIST_R` (200-400) → 更快响应
   - 增大 `KF_DIST_Q` (500-1000) → 更快跟踪目标移动
   - 增大 `KP_DIST` (1500-2000) → 更强追赶力

3. **如果转弯不灵活/过于灵活**:
   - 调整 `KP_BEAR` (1000-2500)
   - 增大低速增益(改代码中 bear_kp_scale: 1.5→2.0)
   - 减小高速增益(改代码中 bear_kp_scale: 0.7→0.4)

### 航向稳定性调优

4. **如果走直线偏一侧**:
   - 调整 `HEADING_KP_MILLI` (500-3000)
   - 调整 `CF_ALPHA` (950-990): 越大越信任陀螺仪，越小越信任编码器
   - 检查编码器标定是否正确

### 搜索效率调优

5. **如果目标丢失后久久找不到**:
   - 适当增加 `SEARCH_ANGULAR_MRADPS` (1000-1500)
   - 延长 `SEARCH_TIMEOUT_S` (8-12s)
   - 检查UWB天线安装角度是否合理

### 跟车距离

6. 调整 `FOLLOW_DISTANCE_MM` (500-2000mm) 和 `DYN_DIST_FACTOR` (0-1000)

## 调试顺序

1. **垫高轮子空跑**: 确认电调解锁，Kalman滤波器正常工作
2. **标定编码器**: 手推1m，记录编码器增量，设置 `TICKS_PER_METER`
3. **验证Kalman效果**: 观看日志中 raw 和 kf 值的差异，确认滤波正常
4. **验证预测跟踪**: 让目标匀速移动，观察 prey 值是否领先 raw
5. **整定速度PID**: 先只留前馈(KI=KD=0)，再加KI消静差、KD抑超调
6. **调整S曲线**: 从保守参数开始(max_jerk=500)，逐步增加至不抖动
7. **校航向闭环**: 直线跑观察偏航，调整 `HEADING_KP_MILLI`
8. **校UWB左右**: 方位方向反了则改 `FR_UWB_LEFT_SIGN` 符号

## 注意事项

1. **编码器 `TICKS_PER_METER` 必须标定**
2. **Kalman R 参数需根据实际UWB噪声调整**: 日志对比 raw/kf 值，确保滤波不过强也不过敏
3. **互补滤波CF_ALPHA**: 默认0.98适合大多数场景，若编码器精度低则增大至0.99
4. **S曲线jerk**: 初始调试建议设 max_jerk=500, max_accel=500, 逐步调高
5. **预测跟踪**: 若目标运动很不规则，可减小predict ahead时间 (代码中0.3s)
6. **无避障**: 本版本不包含任何避障功能
7. **传感器降级**: 编码器掉线退化为前馈开环，IMU掉线跳过航向闭环和互补滤波
8. **失效保护**: 失控保护0.3s内自动停车 (chassis层)
