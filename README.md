# 智能跟随行李箱 · 跟随算法2（跟随 + VFH 避障）

**跟随算法2 = 跟随代码1 + 激光雷达 + 双超声波 + VFH-lite 避障算法。具备完整的感知-决策-控制闭环。**

在跟随代码1的闭环底盘和UWB跟随基础上，增加激光雷达前方180°环境感知、双超声波近场安全冗余以及VFH-lite（向量场直方图）避障择向算法。可自主绕开障碍物，同时保持对目标的跟随。

---

## 与跟随代码1的差异

| 项目 | 跟随代码1 | 跟随算法2 |
|------|-----------|-----------|
| UWB 跟随 | 有 | 有 |
| 激光雷达 (RPLIDAR C1) | **无** | **有**（前方180°） |
| 超声波 (A02YYUW ×2) | **无** | **有**（前左/前右） |
| VFH-lite 避障算法 | **无** | **有** |
| 跟随状态机 | **3态**（IDLE/SEARCH/FOLLOW） | **5态**（IDLE/SEARCH/FOLLOW/AVOID/ESTOP） |
| 障碍物减速调速器 | 无 | 有（线性渐减速） |
| 闭环底盘 | 有 | 有 |
| IMU 航向闭环 | 有 | 有 |

### 核心差异说明

1. **感知能力升级**：跟随代码1仅有UWB目标定位，前方有障碍物时会直接撞上。跟随算法2增加了激光雷达（中远距离3D感知）和双超声波（近场低矮/细杆盲区补盲），形成冗余融合的前方感知。
2. **避障决策**：跟随算法2内置 VFH-lite 算法——将激光雷达点云构建为极坐标障碍物直方图，在自由扇区中选择代价最低（目标方向偏差 + 平滑性）的航向，实现绕障同时不丢失目标方位。
3. **紧急停止（ESTOP）**：前方距离≤紧急阈值时优先紧急制动，并朝开阔侧原地旋转脱困。
4. **多级安全调速**：前方间隙低于安全距离时线性渐减速，而非硬切停，动作更平顺。

## 跟随 + 避障算法详解（follow_avoid.c）

### 状态机（5态）

```
             ┌──────────────────────────────────────┐
             │                                      │
             ▼                                      │
        ┌─────────┐  目标丢失超时    ┌──────────┐   │
        │  IDLE   │ ◄────────────── │ SEARCH   │   │
        │  停车    │  搜索超时(6s)   │ 原地旋转  │   │
        └─────────┘                  └──────────┘   │
             ▲                            │         │
             │  目标重捕                   │ 目标重捕 │
             │                            ▼         │
             │                    ┌──────────────────┤
             │                    │                  │
             │  前方紧急 ◄────────┤     FOLLOW       │
             │                    │  跟随 + 躲避      │
             │                    │                  │
             │                    └──────┬───────────┘
             │                           │ 目标路径被阻挡
        ┌─────────┐                      ▼
        │  ESTOP  │ ◄──── 完全堵死 ┌──────────┐
        │ 紧急停车  │              │  AVOID   │
        │ 原地旋转  │              │ VFH绕障   │
        └─────────┘              └──────────┘
```

### VFH-lite 避障择向

1. **障碍物直方图**：激光雷达360°扫描点云 → 仅保留前方65°×2有效区域 → 按2.5°/扇区映射为极坐标直方图
2. **安全扩张**：对每个障碍物扇区，按机器人半宽/障碍物距离计算角跨度，向两侧扩张，确保不穿过小于车宽的间隙
3. **代价函数**：在未被阻挡的自由扇区中，选择 `cost = w_goal · |扇区-目标方位| + w_smooth · |扇区-上一航向|` 最小的方向
4. **速度调速器**：前方间隙在 `slow_distance` ~ `emergency_distance` 之间线性减速，保障过障速度安全

### 传感器融合策略

| 传感器 | 失效降级策略 |
|--------|-------------|
| 激光雷达 | 退化为仅超声波避障（近场保护） |
| 双超声波 | 退化为仅激光雷达避障（远场为主，丧失近场盲区补盲） |
| UWB | 进入SEARCH→IDLE，等待重捕 |
| IMU | 跳过航向闭环，退化为开环角速度命令 |
| 编码器 | 退化为纯前馈开环驱动 |

## 软件架构：多任务 RTOS + 共享快照

### 任务调度

| 任务 | 优先级 | 栈 | 职责 |
|------|--------|-----|------|
| `uwb_task` | 6 | 4096 | UART1 接收 UWB 目标定位数据（TWR JSON） |
| `lidar_task` | 6 | 4096 | UART2 接收激光雷达360°扫描，转换为障碍物直方图 |
| `ultra_l / ultra_r` | 5 | 3072 | 软件串口轮询读取前左右超声波 |
| `control_task` | 7 | 4096 | 50Hz 控制循环（跟随/避障/航向/底盘驱动） |

IMU 在 `control_task` 内同步读取，不占用独立任务。

### 共享快照（g_shared）

```c
typedef struct {
    SemaphoreHandle_t lock;
    float tgt_distance_m, tgt_bearing_rad;
    uint64_t tgt_ts_us;
    fa_obstacle_field_t field;
    uint64_t field_ts_us;
    float ul_m, ur_m;
    uint64_t ul_ts_us, ur_ts_us;
} shared_t;
```

## 构建与烧录

```bash
cd examples/follow_robot
idf.py set-target esp32s3
idf.py menuconfig   # 配置引脚、PID、避障参数等
idf.py build
idf.py flash monitor
```

Kconfig 菜单位于 `Follow Robot` 菜单下，可配置：
- ESC 引脚/脉宽、编码器引脚/每米脉冲数
- 速度 PID 参数（KP/KI/KD/限幅）
- 轮距/最大轮速
- 跟随距离/停止带/最大速度/Kp
- **紧急距离/缓减速距离/安全距离**（避障关键参数）
- **机器人半宽**（VFH 扇区扩张量）
- IMU 航向闭环增益
- 控制循环频率
- UWB/激光雷达/超声波/I2C 引脚
- 激光雷达前方朝向角度

## 上电调试顺序

1. **垫高轮子空跑**：先确认电调解锁（上电后等待 ESC 自检）
2. **标定编码器方向与每米脉冲**：手推1m，看日志实测速度符号和增量
3. **标定满速轮速**：给最大前进，量实际轮速
4. **整定速度 PID**：先只留前馈看跟随误差，再加 KI 消静差、KD 抑超调
5. **校航向闭环**：直线跑若往一侧偏，调整 `HEADING_KP_MILLI`
6. **校 UWB 左右**：目标方位方向反了则改 `FR_UWB_LEFT_SIGN` 符号
7. **验证雷达朝向**：确认 `LIDAR_FORWARD_DEG` 与实际安装方向一致
8. **整定避障参数**：逐步调节 `emergency_dist_mm` / `slow_dist_mm` / `safe_dist_mm`，确保绕障不贴边且不过早避让

## 注意事项

1. **编码器 `TICKS_PER_METER` 必须标定**：推机器人恰好1米，记录日志中编码器计数差值
2. **GPIO39 作 SDA** 仅 ESP32-S3 支持（经典 ESP32 的 GPIO34–39 仅为输入）
3. **无后向感知**：算法刻意不倒车，过近只停车
4. **激光雷达仅在 0°~65° 和 295°~360° 范围有效**：过滤掉了侧向和后向数据，专注前方避障
5. **超声波使用软件串口**：因 UART0/1/2 已被占用，9600 baud 的低速超声波通过 GPIO 位脉冲模拟 UART
6. **传感器降级**：编码器掉线退化为前馈开环，IMU 掉线跳过航向闭环，雷达掉线退化为纯超声波避障
7. **失效保护**：控制任务卡死会在 0.3 秒内自动停车（chassis failsafe）
